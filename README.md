# Atelier d'écurie Kallithéa, aperçu de test

Page de démonstration de l'atelier d'écurie de [Kallithéa](https://kallithea.fr) : on compose l'implantation d'un projet équestre sur un terrain à l'échelle, en 3D.

Aperçu : https://mariusoffchain.github.io/kallithea-atelier-preview/

Version de test. La demande de devis n'envoie rien depuis cette page, les dimensions de plusieurs bâtiments sont provisoires et aucun prix n'est affiché. La page n'est pas référencée par les moteurs de recherche.

`index.html` est un fichier construit, à ne pas modifier à la main.
